3. এসাইনমেন্ট এর রেজাল্ট পাওয়ার পরে ভুলেও সে ফীডব্যাক গ্রুপে পোস্ট করবেন না।
   ফীডব্যাক বা নম্বর নিয়ে সব আলোচনা সাপোর্ট সেশনে এসে করতে পারবেন। ধরেণ আপনার
   নম্বর ভুল এসেছে, আপনার পাওয়ার কথা ৫ কিন্তু পেয়েছেন ০। টেনশনের কারণ নেই,
   কনফিডেন্ট থাকলে recheck দিবেন । আর যদি ক্লারিফিকেশন চান বা ডিস্কাস করে পরে
   রিচেক দিতে চান তাহলে সাপোর্ট সেশনে এসে ইন্সট্রাক্টরের সাথে আলাপ করবেন।

4. এসাইনমেন্টের recheck ক্লিয়ার হতে সময় লাগে সেক্ষেত্রে অপেক্ষা করতে হয় পরবর্তী
   এসাইনমেন্ট এর আগে পর্যন্ত। যেমনঃ আপনি এসাইনমেন্ট ১ রিচেক দিলেন। কিন্তু
   এসাইনমেন্ট ২ আসার আগে আপনি রেজাল্ট পাননি ১ এর রিচেকের। সেক্ষেত্রে আপনি
   সাপোর্ট সেশনে এসে জানাবেন বা আপডেট জানতে চাইতে পারেন। বা এসাইনমেন্ট ৩ পর্যন্ত
   অপেক্ষা করতে পারেন। এর মধ্যে ক্লিয়ার হয়ে যেতে পারে। তাও, না হলে সাপোর্ট সেশনে
   জানাবেন।

কেনো রিচেকের রেজাল্ট দিতে দেরি হয়?

কারণ, বর্তমান এসাইনমেন্ট এর পেন্ডিং সাবমিশন গুলো প্রথমে চেক করা হয়। তারপর সব
পেন্ডিং এসাইনমেন্ট ক্লিয়ার হলে সেই এসাইনমেন্ট এবং তার আগের পুরনো সকল এসাইনমেন্ট
এর রিচেক রিকুয়েস্ট গুলো ক্লিয়ার করে দেওয়া হয়। সে সাথে আগের বা পুরনো এসাইনমেন্ট
গুলোতে নতুন কোনো এসাইনমেন্ট জমা হলে সেগুলোও চেক করে দেওয়া হয়।
